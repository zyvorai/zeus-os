# Plugins

## Purpose

Preview of partner and custom Zeus OS plugin categories. Install and uninstall are not available yet.

## When to use it

- See planned adapter types (storage, backup, network, monitoring, ticketing, AI)
- Understand that Install buttons are intentionally disabled
- Follow Developer Center for future SDK and webhook docs
- Prefer Marketplace templates for deployable content today

## How to get there

- Route: `/plugins`
- Nav: **Modules → Plugins**
- Related: `/developer-center`, `/marketplace`

## Operate from the console (UX)

1. Open `/plugins` from the sidebar, workspace switcher, or command palette (⌘K / Ctrl+K).
2. Read the PageHead / deck line — confirm it matches: Preview of partner and custom Zeus OS plugin categories. Install and uninstall are not available yet.
3. Use the center’s primary CTA (create, scan, open workbench, ask Zeus when reasoning is required).
4. Deterministic navigation and filters call the router directly — do not round-trip those through Ask Zeus.
5. Pin frequent pages to Favorites (`/favorites`).
6. **Empty / fail:** No data → check auth, namespace filter, and that required operators (KubeVirt/CDI/monitoring) are installed; purpose was: Preview of partner and custom Zeus OS plugin categories. Install and uninstall are not available yet.
7. **Success:** Live inventory or job progress matches the deck line; you can navigate to a related center without re-auth.

Use `https://<host>:30050/` (NodePort) or your ingress URL — never publish lab IPs. HTTPS is required for in-browser VNC. Browse lists are safe; power actions live on workbenches.
