    Page-by-page guides

    Each guide follows the same shape:

    1. Purpose — what this screen is for
    2. When to use it — typical jobs
    3. How to get there — route and nav path
    4. Operate from the console (UX) — concrete clicks after you land
    5. Related pages — where to go next

    Every dashboard route, including screens without a deep guide, is listed in the complete page index.

    Core — VMs and daily operations

    Page What it covers
    Favorites Pinned VM list for quick access: star VMs you care about, search the fleet, and open VNC or serial console deep links.
    Home (Mission Control) Apple.com-style chapter home: greeting hero, Get the highlights (fleet KPIs on a dark band), infrastructure pulse, a light Attention teaser, running machines, and apps/insights — without the heavy triage deck.
    Instance types Browse KubeVirt instance types and preferences — standardized CPU/memory shapes for consistent VM sizing.
    Compare VMs Side-by-side diff of two VMs’ configuration so you can spot drift, clone mistakes, or environment mismatches.
    VM setup (create a machine) Guided creation of a new KubeVirt VM from instance types, preferences, templates, or AI-assisted manifests.
    VM workbench Full-page operations surface for one virtual machine: power, console, hardware, networking, backup panels, guest agent, and remote access.
    VM fleets (VMIRS) Manage VirtualMachineInstanceReplicaSet-style fleets — scale homogeneous VM groups as a unit.
    VM Instances (VMI) List of running VirtualMachineInstance objects — the live pods/instances behind VirtualMachine definitions.
    Virtual Machines Inventory of every KubeVirt virtual machine you can see: live status, filters, and entry into the per-VM workbench.

    Consoles and remote access

    Page What it covers
    ConsoleHub Unified launcher and session manager for browser consoles — multiple VMs, policies, and session visibility.
    Consoles & remote access Reach the guest: graphical VNC, serial text console, and native RDP/SSH via NodePort expose.

    Cluster, storage and images

    Page What it covers
    Blueprints Blueprint Marketplace for one-click application stacks (for example Windows AD, RDS, SQL, IIS, jump boxes) registered in the cluster.
    Enterprise networking Direct management of Cilium-native Egress Gateway policies, BGP peering, L2 announcement policies,
    Customization Profiles Reusable guest customization specs — cloud-init, Windows sysprep/unattend XML, and SSH authorized keys — applied from create/clone flows or onto an existing VM.
    DataVolumes CDI DataVolume inventory — disk import/clone/upload jobs that back VM disks.
    Device Plugins Read-only view of Kubernetes device-plugin resources and GPU capacity reported by the cluster.
    Disk Manager Manage VM disks: attach, hot-plug, resize entry points, and disk inventory beyond the raw PVC list.
    GPU Devices GPU / PCI passthrough inventory: host VGA/3D devices, allocation to VMs, plus a vGPU orchestration panel for mdev profiles and assign actions.
    HPA Monitor and manage Horizontal Pod Autoscalers — replica counts, CPU utilization, and scaling status across namespaces.
    Image Factory Golden Image Factory pipelines that take a customer-supplied OS ISO through VirtIO, updates, optional GuestKit bake, sysprep/generalize, snapshot, and catalog publish.
    Image Library One catalog for golden images, import guidance, and cluster images so operators can pick OS media when creating VMs.
    Image Registry Browse container disk images for KubeVirt VMs — cluster images from running pods, or a reference catalog — then open Create VM with the image prefilled.
    MetalLB & external IPs Operator guidance for LoadBalancer Services (SSH, RDP, and other external access) via MetalLB address pools — not a pool editor UI.
    Networks Multus NetworkAttachmentDefinition management so VMs can attach additional L2 NICs — bridge, macvlan, ipvlan, host-device, or SR-IOV.
    Nodes Kubernetes worker/control-plane node inventory: capacity, conditions, and drain/placement context for VMs.
    Pods Kubernetes pod inventory — including virt-launcher pods that back running VMIs.
    Priority Classes Read-only list of Kubernetes PriorityClass objects — numeric value, global default, preemption policy, and usage.
    PVC Resize Expand existing PersistentVolumeClaims or create empty PVCs. CDI image imports still belong on DataVolumes.
    Runtime Classes Read-only inventory of cluster RuntimeClass objects — handler, scheduling hints, overhead, and usage counts.
    Services Cluster-wide Kubernetes Service inventory for VM SSH/RDP exposes and other workloads — ports, addresses, and YAML in one place.
    Storage Storage and PVC intelligence for the cluster: volumes, capacity signals, and entry points into disk/resize workflows.
    Taints Read-only analysis of node taints and which VMs tolerate them — plus scheduling impact warnings for unschedulable guests.
    Templates Curated VM templates for one-click or guided deploy of known-good shapes.
    VPA List, create, and delete Vertical Pod Autoscalers, and inspect container resource recommendations.

    Observe — health, metrics and incidents

    Page What it covers
    Alerts Zeus-native alerting console — active fired alerts, threshold rules, history, and webhook destinations — separate from PrometheusRule CRDs in Alerting V2.
    APM Application performance dashboard for services, traces, and latency percentiles — when an APM backend is connected to Zeus OS.
    Attention Ranked next steps, live fleet signals (Issue Stream), and day-2 remediation activity — the triage surface that used to live as a heavy block on Home.
    Capacity Cluster capacity and overcommit dashboard — utilization pulse, per-node breakdown, capacity alerts, planning scenarios, and HA/DRS context.
    Containers Pod-centric container inventory with status stats, detail sheet, and (for non-viewers) deploy / apply-YAML shortcuts alongside a deployments panel.
    Custom Metrics Dashboard for operator-defined metrics and their alert rules — create PromQL (or custom) configurations, then watch values and firing alerts.
    Events Live Kubernetes event browser — type, reason, object, message, namespace, count, and age — for correlating cluster noise with VM or workload symptoms.
    Forecasting AI-assisted resource predictions — per-VM and cluster forecasts, capacity recommendations, and seasonal pattern detection — to plan before you run out of headroom.
    Resource Heatmap Cluster-wide utilization heatmap built from per-VM cells rolled up by node — CPU, memory, disk, and network pressure for capacity planning.
    Host Info Read-only view of the Zeus OS host — OS, hardware, disks, NICs, and local services — for operators checking the control-plane node itself.
    Incident chat Lightweight multi-user chat channel for incident collaboration. Marked labs in navigation; messages sync through Zeus OS, while slash commands run locally.
    Incidents Incident center with context and guided remediation — not just a raw alert dump.
    Logs Explorer On-demand log search across pods in a namespace — query text, severity filter, and optional live tail — for day-2 debugging from the dashboard.
    Monitoring Targets Inventory of Prometheus Operator objects in the cluster — ServiceMonitors, Prometheus instances, and PrometheusRule groups — plus high-level monitoring stats.
    Network Info Host network interface inventory for the Zeus OS host — physical, bridge, veth, VM TAP, Cilium, bond, VLAN, and tunnel devices — with traffic counters.
    SLO Manager Service level objective tracker — create availability-style objectives, watch met / burning / breached status, and refresh error-budget posture for the fleet.
    System Health Platform health dashboard — control-plane and Zeus-related component pulse for operators and admins.
    VM Monitor Activity Monitor for the VM fleet — live and historical CPU, memory, network, and disk — with per-VM charts and links into the VM workbench.

    Run — lifecycle, migration and backup

    Page What it covers
    AutoScaler Define policies that resize VMs automatically, and review right-sizing recommendations with their estimated monthly cost impact before applying them.
    Backup Wizard Guided backup workflow for VMs / volumes — complementary to Velero and snapshot managers.
    Cluster Autoscale Read-only status of the cluster autoscaler and its node pools: whether it is enabled, how each pool is sized against its min and max, and what scale-up or scale-down actions it is recommending.
    Live Migrations Plan, dry-run, and execute live VM migrations between nodes with pre-flight checks and history.
    Node Drain A guided five-step wizard for taking a node out of service safely: pick the node, see exactly which VMs will move and which will lose availability, choose a strategy, cordon and drain, then watch it finish.
    Operations One console for the recurring day-2 chores: alert rules, outbound webhooks, quotas, GPU inventory, backup and power and snapshot schedules, RBAC review, quick deploy, cluster context, and labels.
    Snapshots Create and manage VM snapshots (on-demand and scheduled) for point-in-time recovery.
    Velero Velero-backed backup and restore operations for cluster and VM-related resources.
    Windows Licensing Read-only inventory of Windows activation state across your KubeVirt VMs, collected through the guest agent (slmgr). Zeus OS never hosts a KMS or redistributes licenses — it reports what your own activation infrastructure says.
    Workflows Read-only view of the automation workflows registered with Zeus OS: what is scheduled, when each last ran, how reliable it has been, and the template gallery you can copy from.

    Security, compliance and governance

    Page What it covers
    Admission control Read-only inventory of what intercepts writes to your cluster: validating and mutating admission webhooks, Kyverno policy rules, webhook statistics, and recent admission-related events.
    Affinity Rules Surfaces where your affinity and anti-affinity placement intent is not being honoured — which rule is violated, which VMs are affected, and on which node.
    Certificates Tracks the TLS certificates in your cluster and how long each one has left, so an expiry never surprises you. Renewal can be triggered from the table.
    Change Approval A review queue for VM changes: destructive requests wait for a human approver, non-destructive ones are auto-approved, and every decision is recorded with a comment and a timestamp.
    Compliance Scores your VMs against Zeus OS policy checks and gives you a cluster grade, per-category pass rates, and a per-VM breakdown you can export as evidence.
    External Secrets Monitor the ExternalSecret and SecretStore resources that pull credentials from Vault, cloud secret managers, and other providers into Kubernetes — with sync, validate, and delete actions.
    Image Scanning Vulnerability posture for your container and VM images: critical, high, medium, and low counts per image, when each was last scanned, and the scan policies that decide pass or fail.
    OPA Gatekeeper Read-only inventory of your OPA Gatekeeper constraints and constraint templates, with the current violation count and the offending resources behind each one.
    PDB Shows every PodDisruptionBudget in the cluster and whether it currently permits any voluntary disruption — the fastest way to know if a drain will proceed or stall.
    Security Security posture overview — findings, hardening status, and entry into compliance / scanning / policies.
    Tenancy Organise namespaces into tenants, see each tenant's namespace, CPU, and memory footprint, manage who belongs to a tenant, and track quota consumption per namespace.
    Users Shows who you are signed in as and what that identity may do, manages built-in local accounts, and issues revocable API tokens for automation.

    Cost and FinOps

    Page What it covers
    Budget Alerts Monthly spend budgets for the cluster, a tenant or a namespace. Budgets are stored and evaluated on the server from recorded cost history, and alerts go out through your notification channels once per threshold per month. Spend is an estimate from your configured unit prices, not an invoice.
    Chargeback Nav alias for namespace cost allocation / showback. There is no separate Chargeback UI — the link opens Cost Allocation.
    Cost Allocation Namespace-level chargeback view: estimated monthly cost rolled up by namespace, with CPU, memory, and storage share plus per-VM detail.
    Cost Estimator What-if cost calculator for planned VM fleets: adjust count, shape, and unit prices to estimate monthly and annual spend (labs-tier page).
    Cost Intelligence Per-VM and per-namespace spend visibility, trends, and FinOps entry points.
    Costs Cluster cost dashboard: monthly spend trends, namespace and resource-type breakdowns, top expensive VMs, and optimization opportunities.
    Rightsizing Recommendations for idle, oversized, or orphaned resources — turn Cost Intelligence into concrete shape changes.
    SLA Dashboard Live VM up/down posture plus configurable SLO targets (uptime % and latency). Historical uptime and error budget are not synthesized without availability history.
    Spot Savings Nav alias for the Optimization Center. There is no separate Spot Savings page — the link opens resource optimization recommendations and savings tracking.

    Insights, network, delivery and tools

    Page What it covers
    AI Center AI-assisted SRE, migration, and security advisors grounded in cluster evidence (Forge / built-in LLM when configured).
    Anomaly Detector Surfaces VM health, CPU, and memory outliers with risk levels and suggested next actions. The view auto-refreshes about every 10 seconds from live inventory and health scores.
    API Docs Browsable REST reference for Zeus OS: live OpenAPI when available, plus categorized method/path descriptions for VMs, nodes, pods, and more.
    API Playground In-browser HTTP client for Zeus OS REST endpoints: pick a method and path, send authenticated requests, and inspect status, headers, and body.
    ArgoCD Read-only dashboard of Argo CD Applications and Projects — sync and health status for GitOps workloads in the cluster.
    Auto-Remediation Day-2 playbooks and policy controls that respond to common VM failures — crash loops, node pressure migrations, and advisory rightsizing or PVC expansion — with optional closed-loop autonomy.
    Catalog Infrastructure app catalog (Helm-oriented installs) for common day-2 stack pieces: browse categories, search apps, and trigger install.
    Chaos Engineering Controlled fault experiments against VMs — primarily kill virt-launcher pods to validate recovery; other stress types are listed when a fault-injection backend is available.
    CI/CD Pipeline inventory and run history with on-demand trigger controls for cluster-integrated CI/CD definitions.
    Cilium CNI Cilium status, endpoints, policies, Hubble packet flows, VM internet-egress controls, and a VM policy builder — when Cilium is installed in the cluster.
    Cluster Upgrade Version awareness and an upgrade checklist for Kubernetes and KubeVirt — plus VLCM rollout controls — so operators plan upgrades without skipping critical backups and drains.
    Database Ops Day-2 view of database instances and their backups — status, storage, endpoints, and connection details for operator copy-out.
    Debug Host-level diagnostics for the Zeus OS node: live system stats, network interfaces, disk partitions, services, and a downloadable support bundle.
    Dependencies Live graph of resource relationships — nodes, VMs, PVCs, Services, and labeled edges — so you can see what depends on what before a change.
    Deployment Strategies Define and run progressive delivery strategies (Rolling Update, Canary, Blue/Green, Recreate) against Kubernetes workloads, with execute and rollback controls.
    Disaster Recovery Disaster Recovery Center — visual DR plans, RPO/RTO targets, failover test scheduling, and step runbooks for day-2 resilience.
    DNS Derived DNS / FQDN helpers for pods and VMs: search inventory, copy cluster-style names, and map IPs to names operators can use.
    GitOps Compare desired versus actual VM power state, show Flux/Argo cluster stats, and sync power-status drift back toward the intended running/stopped state.
    Helm Releases List, install, upgrade history, rollback, and uninstall Helm releases, and manage chart repositories on the cluster.
    IaC Infrastructure-as-code resource inventory with drift detection and a sync action for IaC-managed objects Zeus OS can see.
    Kernel Info Host hardware and OS inventory: hostname, kernel, CPU, BIOS, PCI devices, and memory modules for the Zeus OS node.
    Kustomize Browse Kustomize bases and overlays, then preview the rendered diff before you apply changes outside the dashboard.
    Multi-Cluster Multi-Cluster Command Center — list federation contexts, view the current cluster overview, and compare up to two clusters side by side.
    Network Flow Zeus Network Center — service map, flows, DNS health, policies, and PacketWolf-backed containment actions, with Cilium/Hubble and cluster metrics as fallbacks when PacketWolf is offline.
    NLP Command Natural-language bar for VM power and lifecycle intents — parse plain English into a confirmed action before execution (labs tier).
    Operators OLM inventory for ClusterServiceVersions, Subscriptions, OperatorGroups, CatalogSources, and InstallPlans with aggregate health stats.
    Optimization Resource optimization recommendations and estimated savings — review rightsizing suggestions and apply supported hotplug/shape changes when enabled.
    PacketWolf VM Guard Network intelligence and VM Shield containment — see allowed/denied flows and apply quarantine / internet-lock profiles (typically Cilium/Hubble backed).
    Performance Testing List and run performance tests defined in the cluster, with live metrics (users/pods tracked, estimated RPS, error rate, latency).
    Placement Advisor Legacy nav entry for smart VM placement. The dashboard redirects this route to Placement, where node scoring and topology-manager recommendations live.
    Placement Heuristic node scores from live topology, plus topology-manager API recommendations, so you can pick a suitable host for VM CPU/memory and affinity needs.
    Progressive Delivery Operate canary deployments and progressive rollouts — traffic weight, health signals, promote, and rollback — from one delivery dashboard.
    Resource Tags Tag coverage and compliance for cluster resources: distribution of keys, untagged inventory, required-tag checks, and bulk apply.
    Mesh Detail Legacy nav entry for service-mesh detail. The dashboard redirects this route to Service Mesh, the Multus NAD and VM attachment inventory.
    Status Page Operator-facing fleet status board: overall operational / degraded / outage banner, per-VM health, and recent Warning events.
    Terminal In-browser cluster shell: pick a pod/container, open an authenticated WebSocket session, and run commands with multi-tab support.
    Topology Mgr Node topology detail for NUMA zones, CPU pins, device allocations, and topology policies — deeper than the live map on Topology.
    Topology Live map of infrastructure relationships — nodes, VMs, networks, and dependencies visualized.
    Webhook Tester Validate alert webhook delivery: test configured alert webhooks or POST a custom payload to any URL and inspect latency and response.
    Widgets Customizable dashboard widget grid (VM count, capacity, health, events, favorites, alerts) with layout persistence in the browser.

    Product centers and wizards

    Page What it covers
    Application Center Group VMs into business applications with workspace scoping, health pulse, and an inspector for protection and membership.
    Approvals Single inbox for decisions waiting on you — day-2 remediations pending approval and change requests.
    Auth audit log Login and security event table sourced from auth-audit.jsonl on the Zeus OS data volume (ZEUS_OS_DATA_DIR).
    Backup & DR Recovery Theatre hub — backup stats plus shortcuts to Velero, restore, snapshots, DR, and backup wizards.
    Console Sessions Legacy route that redirects to ConsoleHub’s active sessions tab. Bookmarks and Settings links still resolve.
    Developer Center Operator and integrator hub for REST docs, API playground, CLI examples, webhooks, and plugin SDK entry points.
    Edge Center Guidance hub for branch clusters, air-gapped operation, and sync or compliance posture tied to multi-cluster views.
    Forge Native AI module hub — prompt handoff from AI Center, links to AI providers and GPU passthrough. Dedicated agent builder is not shipped on this page yet.
    Identity Center Landing hub for authentication and access governance — links to SSO, LDAP, MFA, Users & RBAC, auth audit, and API tokens.
    Machine Finder Browse the datacenter → cluster → host → VM hierarchy, then jump into Machine Runway for fleet operations.
    Kubernetes Center Hub for the container layer under your Zeus virtual datacenter — cluster pulse plus shortcuts to pods, services, nodes, and related day-2 tools.
    Marketplace Browse and deploy VM templates and blueprints — search, OS and category filters, favorites, AI draft assist, and a deploy wizard.
    Migration Command Center VMware exit planning — migration waves, Transiva discovery handoff, preflight blockers, and wave readiness. Zeus OS does not perform VMware import itself.
    Cluster onboarding Guided preflight for a new Zeus OS cluster — platform readiness, Cilium status check, and cluster info — then links into core navigation.
    Patch Center Windows and Linux patch readiness across running VMs — risk signals, maintenance-window links, and compliance handoff.
    Plugins Preview of partner and custom Zeus OS plugin categories. Install and uninstall are not available yet.
    Reports Executive and operational report catalog — shortcuts into health, protection, DR, security, network, cost, audit, and compliance exports.
    Restore Wizard Guided Velero restore — select a completed backup, configure target namespace and PV restore, then monitor restore phase to completion.
    Support Operator support hub — download a redacted diagnostics bundle and jump to health, debug, API docs, audit, and terminal tools.
    Task Center Long-running operations inbox — migrations, backups, and platform jobs with status, progress, and cancel when supported.
    Time Machine Cluster DVR and per-VM flight recorder — scrub recorded state over time. Frames come from the server-side sampler ring buffer.
    VM Groups Label-based VM groups with bulk start, stop, and restart across matching members.
    War Room Live incident assembly — active incident, affected VMs and nodes, recommended actions, pending remediations, and a warning-event feed in one place.
    Resource Canvas Spatial map of compute, storage, networking, and AI entry points — click a node to open its window.

    Settings

    Page What it covers
    Settings — Advanced Shortcuts into platform, debug, and developer tooling, plus keyboard shortcuts and build information.
    Settings — AI providers Register and manage the language-model providers that power Zeus OS AI features, plus routing rules, API keys, stored memory, and the prompt library.
    Settings — API access Everything needed to automate against Zeus OS: scoped API tokens, the OpenAPI specification, rate-limit behaviour, and the FinOps change audit.
    Settings — Appearance Control how the Zeus OS shell looks and behaves: Light or Dark theme, wallpaper, glass and motion effects, sidebar mode, and the dock.
    Settings — Backup & DR Configuration entry points for Velero backups and disaster recovery, linking settings to the operational backup centers.
    Settings — General Server information and dashboard-wide preferences: what build you are running and how lists and cards behave for your account.
    Settings — Network Entry point for network-related configuration and the PacketWolf network-intelligence integration.
    Settings — Security Security-related configuration surfaced in the UI: active product edition, identity and SSO panels, browser console access policy, and a link into the security overview.
    Settings Configure the Zeus OS experience and platform integrations: general, appearance, network, security, backup/DR, AI providers, API access, and advanced options.
